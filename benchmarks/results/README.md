# STRATA Benchmark Results

This directory stores reproducible benchmark result datasets, raw latency distributions (HDR Histograms), and recall-accuracy profiles generated by the benchmark suite.

## Policy on Measurements

As per architectural correctness standards:
- No fabricated, synthetic, or mock measurements are committed.
- All numbers recorded here must originate from verified automated benchmark harness runs (`benchmarks/run_all.sh` or CI bench workflows).
- Real results will be committed following Phase 1 & 2 baseline evaluations.
