# STRATA End-to-End Demo

This directory contains end-to-end demonstrations illustrating STRATA's core capabilities:

1. **Semantic Document Search with Structured Filtering**:
   Vector embeddings paired with user-level access tags and category constraints.

2. **E-Commerce Hybrid Retrieval**:
   Combining dense product image embeddings with sparse BM25 keyword matching and stock/price filters.
